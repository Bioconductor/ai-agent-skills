# Knowledge for bioc-pkg-review

- `rubric.yaml`, `rubric.md`: generated by `python3 rubric.py --export` in
  Bioconductor/BiocPkgReviewer. Do not edit; the header carries the rubric hash and date.
- `package-review-checklist.md`: offline fallback copy of the published Package Review Checklist
  (v2.0.0). The skill fetches the latest from pkgrevdocs `devel` when it can and says when it
  could not.
